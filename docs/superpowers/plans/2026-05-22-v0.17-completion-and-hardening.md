> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.17 with four coordinated tracks that close the loop on v0.16's Tool Result Envelope: (A) Telemetry completion — streaming chat appends `UsageRecord`, routing-based Savings card with `routingBaseline` config, `usage.jsonl` auto-trim at 10MB→5MB; (B) GUI per-tool envelope rendering — read_file / list_files / search_files / run_command custom views + uniform failure card with 16-code hint table + `[Copy cursor]`; (C) Windows hardening + cross-OS CI — `runChild` shell quoting, junction-point fixture, GitHub Actions matrix; (D) Tidy — MCP server `TIERKIT_VERSION`, `docs/MCP_BRIDGE.md` v0.16 rewrite, `read_file` returns `stale-cursor` (not `not-found`) on file-deleted.

**Architecture:** Telemetry and savings live in `@tierkit/core`; envelope renderers are inline JS in `gui.ts`'s existing render dispatcher; Windows quoting and reparse-point checks slot into `runChild()` from v0.16; the cross-OS matrix is a new `.github/workflows/ci.yml`. No new packages; all changes layer on existing v0.16 structure.

**Tech Stack:** TypeScript, Node.js (filesystem + spawn), Vitest, pnpm workspaces, GitHub Actions. No new runtime dependencies.

**Spec:** [docs/superpowers/specs/2026-05-22-v0.17-completion-and-hardening-design.md](../specs/2026-05-22-v0.17-completion-and-hardening-design.md)

**Non-negotiables (from spec, BINDING):**

1. `routingBaseline` defaults to `"claudeCode"` when absent. `"(no baseline configured)"` is shown ONLY when the resolved profile is missing OR has no `cost` data.
2. `computeRoutingSavings` MUST filter `type !== "mcp-tool"` before summing — `usage.jsonl` is heterogeneous (LLM-call + MCP-tool records).
3. `usage.jsonl` size-check + auto-trim happens INSIDE `appendUsage` so every code path benefits automatically.
4. Streaming chat (`openaiCompat.ts:385+`) appends a `UsageRecord` on stream end. Partial streams write `ok: false, failureCode: "stream-aborted"`.
5. Envelope renderer dispatch table maps BOTH `search_files` (Agent) AND `tierkit.codebase_search` (MCP) to the same renderer.
6. `[Copy cursor]` button ships in v0.17. `[▶ Continue]` button deferred to v0.17.1 — Tierkit core has no `POST /v1/tool-call`.
7. `run_command` approval-required behavior unchanged since v0.15.0 — classify-only, no execution. Wording in GUI hints says "v0.17 still" with history note.
8. Windows CI matrix runs `pnpm build` + `pnpm test` on `ubuntu-latest`, `macos-latest`, `windows-latest`. `fail-fast: false`.
9. `runChild`'s `quoteForWindowsShell` only quotes when string contains shell-meaningful chars. macOS/Linux passthrough (shell:false).

Add a helper before `appendUsage`:

```ts
/**
 * In-place trim of a usage log file: keep only the most recent ~targetBytes
 * worth of complete lines, discard older ones. Atomic via tmp + rename.
 *
 * Called from appendUsage when file size exceeds TRIM_TRIGGER_BYTES. The
 * resulting file is back under TRIM_TARGET_BYTES, so the next ~5 MB of
 * appends can accumulate before the next trim.
 */
async function trimUsageLog(filePath: string, targetBytes: number): Promise<void> {
  const raw = await fs.readFile(filePath, "utf8");
  const lines = raw.split("\n").filter((l) => l.length > 0);
  // Walk from the end backwards, accumulating bytes until we hit targetBytes.
  const kept: string[] = [];
  let keptBytes = 0;
  for (let i = lines.length - 1; i >= 0; i--) {
    const lineSize = Buffer.byteLength(lines[i]!, "utf8") + 1; // +1 for newline
    if (keptBytes + lineSize > targetBytes && kept.length > 0) break;
    kept.unshift(lines[i]!);
    keptBytes += lineSize;
  }
  // Atomic: write to tmp, rename over the original.
  const tmp = `${filePath}.tmp-${process.pid}-${Date.now()}`;
  await fs.writeFile(tmp, kept.join("\n") + (kept.length > 0 ? "\n" : ""));
  await fs.rename(tmp, filePath);
}
```

Modify `appendUsage` to check size and trim BEFORE appending. Replace the existing function body:

```ts
export async function appendUsage(filePath: string, record: UsageRecord): Promise<void> {
  await fs.mkdir(path.dirname(filePath), { recursive: true });
  // Cheap size check; trim if we're over the trigger. Trim is rare (every ~5MB
  // of accumulated entries) so this stat() is essentially free.
  try {
    const stat = await fs.stat(filePath);
    if (stat.size > TRIM_TRIGGER_BYTES) {
      await trimUsageLog(filePath, TRIM_TARGET_BYTES);
    }
  } catch (err) {
    if ((err as NodeJS.ErrnoException).code !== "ENOENT") throw err;
    // File doesn't exist yet — appendFile will create it.
  }
  await fs.appendFile(filePath, JSON.stringify(record) + "\n", "utf8");
}
```

```ts
import type { UsageRecord } from "./usageLog.js";
import { estimateCost } from "./usageLog.js";
import type { ModelProfile } from "../model/ModelProfile.js";

export interface RoutingSavingsSummary {
  /** profileId or model identifying the baseline used for cost estimation. */
  baselineProfileId: string;
  baselineDisplayName: string;
  /** Sum of inputTokens from eligible local-device calls in the window. */
  inputTokensRouted: number;
  /** Sum of outputTokens from eligible local-device calls in the window. */
  outputTokensRouted: number;
  /** USD that WOULD have been spent if the routed traffic had gone to the baseline. */
  estimatedCostSaved: number;
  /** Count of local-device successful LLM calls in the window. */
  cloudCallsAvoided: number;
  /** ISO timestamp of the window start (i.e. the `since` arg). */
  windowStart: string;
}

/**
 * Computes routing savings for the window [since, now]. Filters:
 *   1. Records with `type === "mcp-tool"` are NOT LLM calls — skipped.
 *   2. `tier === "local-device"` — only locally-served calls count as savings.
 *   3. `ok === true` — failed calls saved nothing.
 *   4. `timestamp >= since`.
 *   5. Records with missing or NaN inputTokens / outputTokens are skipped.
 *
 * The estimated cost is computed once over the summed tokens (linear in
 * estimateCost), not per-record.
 */
export function computeRoutingSavings(
  records: UsageRecord[],
  baseline: ModelProfile,
  since: Date,
): RoutingSavingsSummary {
  const sinceMs = since.getTime();
  let inputTokens = 0;
  let outputTokens = 0;
  let count = 0;
  for (const r of records as Array<UsageRecord & { type?: string }>) {
    if (r.type === "mcp-tool") continue;
    if (r.tier !== "local-device") continue;
    if (r.ok !== true) continue;
    const ts = Date.parse(r.timestamp);
    if (!Number.isFinite(ts) || ts < sinceMs) continue;
    if (!Number.isFinite(r.inputTokens) || !Number.isFinite(r.outputTokens)) continue;
    inputTokens += r.inputTokens;
    outputTokens += r.outputTokens;
    count += 1;
  }
  return {
    baselineProfileId: baseline.model,
    baselineDisplayName: baseline.displayName ?? baseline.model,
    inputTokensRouted: inputTokens,
    outputTokensRouted: outputTokens,
    estimatedCostSaved: estimateCost(baseline, inputTokens, outputTokens),
    cloudCallsAvoided: count,
    windowStart: since.toISOString(),
  };
}
```

/**
 * cmd.exe-friendly quoting for Windows shell:true spawns. Quotes the string
 * only when it contains a shell-meaningful character; embedded quotes are
 * doubled per cmd.exe convention. Returns the input unchanged when no quoting
 * is needed.
 *
 * Used internally by runChild when process.platform === "win32".
 */
export function quoteForWindowsShell(s: string): string {
  if (!/[\s&|<>^"]/.test(s)) return s;
  return `"${s.replace(/"/g, '""')}"`;
}

function checkSubprocessCommandPaths(cfg: TierkitConfig): DoctorCheck[] {

## Migration from v0.15
