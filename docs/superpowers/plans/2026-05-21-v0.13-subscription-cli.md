# v0.13 Subscription CLI Provider — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Claude Code as the first subscription-CLI provider so Tierkit can route OpenAI-compatible requests to a local `claude` subprocess; fix pinned-profile silent fallback so explicit profile choices fail loudly.

**Architecture:** Bottom-up — schema/constants → estimator → SubscriptionCliProvider base → ClaudeCodeProvider → viability → router ordering → openaiCompat policy → seed migration + bundled profile → GUI → docs. Each phase is self-contained and testable; runtime/router changes come late so test breakage stays bounded.

**Tech Stack:** TypeScript, zod, Vitest, pnpm workspaces. Tests in `packages/core/test/*.test.ts` (flat). Subprocess tests use real `node -e "..."` fake-CLI scripts written to temp files (same style as `test/providerStream.test.ts` which spins up a real HTTP mock server) — **no `vi.mock`**.

**Spec:** [docs/superpowers/specs/2026-05-21-v0.13-subscription-cli-design.md](../specs/2026-05-21-v0.13-subscription-cli-design.md)

**Non-goals (v0.13.0):** tool-call bridging, Codex CLI (planned for v0.13.1 via the same `SubscriptionCliProvider` base), native SSE streaming from subprocess, telemetry.

```ts
/**
 * Internal token estimator for subprocess providers whose CLI does not report
 * usage. Deliberately dependency-free and approximate. CJK characters
 * (Hangul / CJK Unified / Hiragana / Katakana) count ~2 chars/token; everything
 * else ~4 chars/token. The shape matters more than the exact number — Tierkit
 * surfaces `usageSource: "estimated"` so consumers know the count is a guess.
 */
export function estimateTokensFromText(text: string): number {
  if (!text) return 0;
  let cjk = 0;
  for (const ch of text) {
    const cp = ch.codePointAt(0);
    if (cp === undefined) continue;
    if (
      (cp >= 0x3040 && cp <= 0x30FF) ||  // Hiragana + Katakana
      (cp >= 0x3400 && cp <= 0x9FFF) ||  // CJK Unified (incl. Ext-A)
      (cp >= 0xAC00 && cp <= 0xD7A3)     // Hangul Syllables
    ) cjk++;
  }
  const nonCjk = text.length - cjk;
  return Math.max(1, Math.ceil(cjk / 2 + nonCjk / 4));
}
```

```ts
import { spawn } from "node:child_process";
import type { ModelProfile } from "../ModelProfile.js";
import type { ProviderClient, ProbeResult } from "./types.js";
import { ProviderError } from "./types.js";
import type { ChatRequest, ChatResult, ChatMessage, StreamEvent } from "./chatTypes.js";
import { estimateTokensFromText } from "./estimateTokens.js";

export interface SubscriptionCliParsedResult {
  content: string;
  inputTokens?: number;
  outputTokens?: number;
  raw: unknown;
}

interface SpawnOutcome {
  stdout: string;
  stderr: string;
  code: number | null;
  timedOut: boolean;
  stdoutTruncated: boolean;
  stderrTruncated: boolean;
  spawnError?: NodeJS.ErrnoException;
}

interface SpawnOptions {
  timeoutMs: number;
  maxStdoutBytes: number;
  maxStderrBytes: number;
  stdin?: string;
}

function runSubprocess(command: string, args: string[], opts: SpawnOptions): Promise<SpawnOutcome> {
  return new Promise((resolve) => {
    const child = spawn(command, args, { stdio: ["pipe", "pipe", "pipe"] });
    let stdout = "";
    let stderr = "";
    let stdoutTruncated = false;
    let stderrTruncated = false;
    let timedOut = false;

    const timer = setTimeout(() => {
      timedOut = true;
      try { child.kill("SIGKILL"); } catch { /* already exited */ }
    }, opts.timeoutMs);

    child.stdout!.on("data", (chunk: Buffer) => {
      if (stdout.length >= opts.maxStdoutBytes) { stdoutTruncated = true; return; }
      const remaining = opts.maxStdoutBytes - stdout.length;
      stdout += chunk.length > remaining ? chunk.toString("utf8", 0, remaining) : chunk.toString("utf8");
      if (chunk.length > remaining) {
        stdoutTruncated = true;
        try { child.kill("SIGKILL"); } catch { /* */ }
      }
    });
    child.stderr!.on("data", (chunk: Buffer) => {
      if (stderr.length >= opts.maxStderrBytes) { stderrTruncated = true; return; }
      const remaining = opts.maxStderrBytes - stderr.length;
      stderr += chunk.length > remaining ? chunk.toString("utf8", 0, remaining) : chunk.toString("utf8");
      if (chunk.length > remaining) stderrTruncated = true;
    });

    child.on("error", (err: NodeJS.ErrnoException) => {
      clearTimeout(timer);
      resolve({ stdout, stderr, code: null, timedOut, stdoutTruncated, stderrTruncated, spawnError: err });
    });
    child.on("close", (code) => {
      clearTimeout(timer);
      resolve({ stdout, stderr, code, timedOut, stdoutTruncated, stderrTruncated });
    });

    if (opts.stdin !== undefined) {
      child.stdin!.end(opts.stdin, "utf8");
    } else {
      child.stdin!.end();
    }
  });
}

function serializeMessages(messages: ChatMessage[]): string {
  const labelFor = (role: string): string => {
    if (role === "system" || role === "developer") return "System";
    if (role === "assistant") return "Assistant";
    if (role === "tool") return "Tool result";
    return "User";
  };
  return messages
    .map((m) => `${labelFor(m.role)}:\n${typeof m.content === "string" ? m.content : ""}`)
    .join("\n\n");
}

function pickNonNegativeNumber(v: unknown): number | undefined {
  if (typeof v !== "number") return undefined;
  if (!Number.isFinite(v) || v < 0) return undefined;
  return v;
}

export abstract class SubscriptionCliProvider implements ProviderClient {
  abstract buildArgs(profile: ModelProfile): string[];
  abstract parseStdout(stdout: string): SubscriptionCliParsedResult;

  async probe(profile: ModelProfile, _env: Record<string, string | undefined>): Promise<ProbeResult> {
    const t = profile.transport;
    if (!t || t.type !== "subprocess") {
      return { ok: false, code: "not-implemented", message: "profile has no subprocess transport", latencyMs: 0 };
    }
    const started = Date.now();
    const out = await runSubprocess(t.command, t.healthCheckArgs, {
      timeoutMs: Math.min(1_500, t.timeoutMs),
      maxStdoutBytes: 10_000,
      maxStderrBytes: 10_000,
    });
    const latencyMs = Date.now() - started;
    if (out.spawnError && (out.spawnError.code === "ENOENT" || out.spawnError.code === "EACCES")) {
      return { ok: false, code: "cli-not-found", message: out.spawnError.message, latencyMs };
    }
    if (out.timedOut) {
      return { ok: false, code: "cli-healthcheck-failed", message: "healthcheck timed out", latencyMs };
    }
    if (out.code !== 0) {
      return { ok: false, code: "cli-healthcheck-failed", message: out.stderr.trim() || `exit ${out.code}`, latencyMs };
    }
    return { ok: true, latencyMs };
  }

  async chat(
    profile: ModelProfile,
    request: ChatRequest,
    _env: Record<string, string | undefined>,
  ): Promise<ChatResult> {
    const t = profile.transport;
    if (!t || t.type !== "subprocess") {
      throw new ProviderError("not-implemented", "profile has no subprocess transport");
    }
    const prompt = serializeMessages(request.messages);
    const started = Date.now();
    const out = await runSubprocess(t.command, this.buildArgs(profile), {
      timeoutMs: t.timeoutMs,
      maxStdoutBytes: t.maxStdoutBytes,
      maxStderrBytes: t.maxStderrBytes,
      stdin: prompt,
    });
    const latencyMs = Date.now() - started;

    if (out.spawnError && (out.spawnError.code === "ENOENT" || out.spawnError.code === "EACCES")) {
      throw new ProviderError("cli-not-found", out.spawnError.message);
    }
    if (out.timedOut) throw new ProviderError("cli-timeout", out.stderr.trim() || "subprocess exceeded timeoutMs");
    if (out.stdoutTruncated) throw new ProviderError("cli-output-too-large", "stdout exceeded maxStdoutBytes");
    if (out.code !== 0) throw new ProviderError("cli-exit-nonzero", out.stderr.trim() || `exit ${out.code}`);

    let parsed: SubscriptionCliParsedResult;
    try {
      parsed = this.parseStdout(out.stdout);
    } catch {
      const trimmed = out.stdout.trim();
      if (!trimmed) throw new ProviderError("cli-empty-output", out.stderr.trim() || "empty stdout");
      parsed = { content: trimmed, raw: out.stdout };
    }
    if (!parsed.content) {
      throw new ProviderError("cli-empty-output", out.stderr.trim() || "parser returned empty content");
    }

    const inputTokens = pickNonNegativeNumber(parsed.inputTokens);
    const outputTokens = pickNonNegativeNumber(parsed.outputTokens);
    const hasFullUsage = inputTokens !== undefined && outputTokens !== undefined;

    return {
      ok: true,
      content: parsed.content,
      inputTokens:  hasFullUsage ? inputTokens!  : estimateTokensFromText(prompt),
      outputTokens: hasFullUsage ? outputTokens! : estimateTokensFromText(parsed.content),
      provider: profile.provider,
      model: profile.model,
      latencyMs,
      usageSource: hasFullUsage ? "provider-reported" : "estimated",
    };
  }

  async *stream(
    profile: ModelProfile,
    request: ChatRequest,
    env: Record<string, string | undefined>,
  ): AsyncIterable<StreamEvent> {
    yield { type: "start", provider: profile.provider, model: profile.model };
    try {
      const r = await this.chat(profile, request, env);
      if (!r.ok) {
        yield { type: "error", code: "provider-failed", message: "chat failed" };
        return;
      }
      yield { type: "delta", text: r.content };
      yield { type: "usage", inputTokens: r.inputTokens, outputTokens: r.outputTokens };
      yield { type: "end" };
    } catch (err) {
      const e = err as ProviderError;
      yield { type: "error", code: e.code || "provider-failed", message: e.message };
    }
  }
}
```

```ts
import type { ModelProfile } from "../ModelProfile.js";
import { SubscriptionCliProvider, type SubscriptionCliParsedResult } from "./subscriptionCli.js";

function pickNumber(...vs: unknown[]): number | undefined {
  for (const v of vs) {
    if (typeof v === "number" && Number.isFinite(v) && v >= 0) return v;
  }
  return undefined;
}

export class ClaudeCodeProvider extends SubscriptionCliProvider {
  buildArgs(profile: ModelProfile): string[] {
    return [...(profile.transport!.args ?? [])];
  }

  parseStdout(stdout: string): SubscriptionCliParsedResult {
    const trimmed = stdout.trim();
    let raw: unknown;
    try { raw = JSON.parse(trimmed); }
    catch { return { content: trimmed, raw: trimmed }; }

    const r = (raw && typeof raw === "object") ? (raw as Record<string, unknown>) : null;
    const content =
      (r && (typeof r.result === "string"  ? r.result :
             typeof r.content === "string" ? r.content :
             typeof r.text === "string"    ? r.text :
             typeof r.message === "string" ? r.message : undefined)) ?? trimmed;

    const usage = (r && typeof r.usage === "object" && r.usage !== null)
      ? (r.usage as Record<string, unknown>) : undefined;
    const inputTokens  = pickNumber(usage?.input_tokens,  usage?.inputTokens);
    const outputTokens = pickNumber(usage?.output_tokens, usage?.outputTokens);

    return {
      content: typeof content === "string" ? content : JSON.stringify(content),
      ...(inputTokens  !== undefined ? { inputTokens  } : {}),
      ...(outputTokens !== undefined ? { outputTokens } : {}),
      raw,
    };
  }
}
```

```ts
  tier: ModelTier,
  taskType: string,
): string[] {
```

```ts
import fs from "node:fs/promises";
import path from "node:path";
import type { ModelProfileMap } from "../model/ModelProfile.js";

const CONFIG_FILE = "tierkit.config.json";

export interface MigrateSeedDefaultDisabledInput {
  cwd: string;
  defaultProfiles: ModelProfileMap;
}

/**
 * Seeds bundled `defaultDisabled: true` profiles into the workspace's
 * `disabledProfileIds` exactly once per profile id. Records the seed in
 * `migrations.defaultDisabledSeededProfileIds` so a later user-driven enable
 * is never undone by a future load. Idempotent.
 */
export async function migrateSeedDefaultDisabled(
  input: MigrateSeedDefaultDisabledInput,
): Promise<void> {
  const file = path.join(input.cwd, CONFIG_FILE);
  let raw: any;
  try {
    raw = JSON.parse(await fs.readFile(file, "utf8"));
  } catch (err: any) {
    if (err && err.code === "ENOENT") return;
    throw err;
  }
  if (!raw || typeof raw !== "object") return;

  const disabled = new Set<string>(Array.isArray(raw.disabledProfileIds) ? raw.disabledProfileIds : []);
  const seeded = new Set<string>(
    Array.isArray(raw.migrations?.defaultDisabledSeededProfileIds)
      ? raw.migrations.defaultDisabledSeededProfileIds
      : [],
  );

  let changed = false;
  for (const [id, profile] of Object.entries(input.defaultProfiles)) {
    if (!profile || (profile as any).defaultDisabled !== true) continue;
    if (seeded.has(id)) continue;
    if (!disabled.has(id)) disabled.add(id);
    seeded.add(id);
    changed = true;
  }
  if (!changed) return;

  raw.disabledProfileIds = Array.from(disabled);
  raw.migrations = { ...(raw.migrations ?? {}), defaultDisabledSeededProfileIds: Array.from(seeded) };

  // Atomic write — write to tmp + rename.
  const tmp = `${file}.tmp-${process.pid}-${Date.now()}`;
  await fs.writeFile(tmp, JSON.stringify(raw, null, 2), "utf8");
  await fs.rename(tmp, file);
}
```

```markdown
## v0.13.0 — Subscription CLI (Claude Code)

### BREAKING

- Pinned model profiles no longer silently fall back to local profiles. A
  pinned profile that fails viability (missing API key, missing CLI binary,
  Ollama unreachable, model not installed, etc.) now returns HTTP 502 with
  `{ error: { type, profileId, reason, message } }`. To opt back into fallback
  routing, use `model: "auto"`.

### Added

- `claude-code` subscription-CLI provider — Claude Code CLI is invoked as a
  subprocess with `-p --output-format json`. Multi-turn messages are serialized
  with role-prefixed blocks. text-only completions (tool-call bridging is
  deferred to a later release).
- Bundled `claudeCode` profile (`defaultDisabled: true`). The first workspace
  load adds it to `disabledProfileIds` via the new
  `migrateSeedDefaultDisabled`; once seeded, enabling it never re-disables.
- `ModelProfile.transport`, `ModelProfile.displayName`,
  `ModelProfile.defaultDisabled` (zod schema additions).
- `SUBPROCESS_PROVIDERS` shared constant.
- Within-tier `paymentModel` ordering (free → flat-rate → per-token) as the
  primary sort key in `sortProfilesForTier`. Tier order itself (local →
  private-remote → public-cloud) is unchanged.
- `ChatResult.usageSource: "provider-reported" | "estimated"` so consumers can
  tell estimated token counts from real ones.
- SSE stream degrade for subprocess providers — `stream: true` is honored by
  emitting a single-delta SSE stream with
  `tierkit.warning: "stream-degraded-to-non-stream"` on the first and final
  chunks. Routing order is **not** changed by `stream: true`.
- `tierkit.profileId` / `usageSource` / `warning` envelope on chat-completion
  responses (both streaming and non-streaming).
- `/v1/models/test` accepts `smoke: true` (runs a short chat after probe) and
  `ignoreDisabled: true` (allows testing without enabling first).
- GUI: viability badge, Test button with confirm + result panel, one-time
  pinned-no-fallback banner, Recent Activity envelope display.

### Internal

- `migrations.defaultDisabledSeededProfileIds` and `notices.*` markers in
  `TierkitConfig` so one-shot behaviors run exactly once per workspace.
```
