# Context Compression v1.7-spike — Local-first Token Firewall

**Date:** 2026-05-19
**Status:** Approved
**Scope:** `@tierkit/core` + `@tierkit/cli` — new `context-compression` module + 4 CLI commands
**Semver:** 0.11.0 (no breaking changes, additive only)

## Problem

Tierkit today routes a task to a single model and streams the response. When the chosen model is a public-cloud profile (Claude, GPT, Gemini), the full task — and whatever context the caller assembled — is sent verbatim to a paid endpoint. There is no mechanism to reduce cloud token usage by preprocessing context locally.

The strategic direction is to reposition Tierkit as a **local-first token firewall** for AI coding agents: before expensive cloud models see a project, local processing should classify, retrieve, compress, redact, and structure repository context so the cloud call works from a minimal high-signal prompt.

The full vision (local LLM rerankers, ModelRole system, CompressionMode enum, OpenAI-endpoint auto-compression, agent loop integration) is large and unverified. This spec scopes the **first vertical slice** — a deterministic, LLM-free context compression pipeline exposed as 4 one-shot CLI commands — whose purpose is to **measure whether compressed prompts maintain response quality versus baseline**. The outcome of this spike decides whether v1.8+ invests in the larger design.

## Non-Goals

This slice exists to answer one question: *does deterministic context compression reduce cloud tokens without degrading response quality on real coding tasks?* The following are explicitly out of scope and deferred:

| Item | Deferred to |
| --- | --- |
| LLM-based file ranker (`file-ranker` role) | v1.8 |
| LLM-based context compressor (`context-compressor` role) | v1.8 |
| `ModelRole` system (`task-classifier`, `cloud-prompt-builder`, etc.) | v1.8+ |
| `CompressionMode` enum (`off`/`light`/`standard`/`aggressive`/`cloud-minimal`) | v1.8+ |
| `--compress` CLI flag | v1.8+ |
| OpenAI-compatible endpoint automatic compression | v1.9+ |
| Agent loop integration (Claude Code / Roo / Cline / Continue auto-wrap) | v1.9+ |
| GUI Token Savings card | v1.8+ |
| HTTP endpoints (`/v1/context/build`, `/v1/context/:id/send`, etc.) | v1.8+ |
| Import graph expansion ("referenced by top file") | v1.8+ |
| tree-sitter based skeleton extraction | v1.8+ |
| LLM-based response quality judge | undecided |
| Parallel compare execution (`--parallel`) | v1.8 candidate |
| Multi-compare per artifact | v1.8 candidate |
| `--diff` flag (auto-diff of responses) | v1.8 candidate |

## Design

### 1. Architecture & file layout

New module `@tierkit/core/src/context-compression/` holds all deterministic logic. Three new usecases. Four new CLI commands. **No existing modules change behavior** — only additive surface.

```
packages/core/src/
  context-compression/                # NEW — all deterministic logic
    types.ts                          # ContextArtifact, RelevantFile, FileExcerpt, ContextBudget, ...
    schema.ts                         # zod schemas + ContextCompressionConfigSchema
    extractKeywords.ts                # task → string[] (stopword filter, identifier extraction, cap=12)
    collectCandidates.ts              # ripgrep wrapper, ignore-globs, filename match
    rankCandidates.ts                 # score = termHitScore + pathBonus + mtimeBonus
    extractSkeleton.ts                # language-aware regex (ts/tsx/js/jsx/py/go/rs)
    extractHotspots.ts                # matched-line ± N windows, merge adjacent, top-K
    buildPromptMd.ts                  # template render → prompt.md content
    estimateTokens.ts                 # chars/4 ceil
  usecases/
    buildCompressedContext.ts         # NEW — orchestrator, write-side-effect-free
    sendCompressedContext.ts          # NEW — read artifact + delegate to runRoute
    compareCompressedContext.ts       # NEW — baseline + compressed, mutate artifact
  runtime/
    contextArtifactStore.ts           # NEW — .tierkit/runtime/context-artifacts/<id>/ read/write
  config/
    ConfigSchema.ts                   # MODIFY — add optional `contextCompression` section
  index.ts                            # MODIFY — re-export new types/schemas/usecases

packages/cli/src/commands/
  context/                            # NEW
    ContextBuildCommand.ts            # tierkit context build "<task>"
    ContextShowCommand.ts             # tierkit context show <id> [--json]
    ContextSendCommand.ts             # tierkit context send <id> --profile <id>
    ContextCompareCommand.ts          # tierkit context compare <id> --profile <id>
  cli.ts                              # MODIFY — register 4 new commands
```

**Runtime data layout** (inside `.tierkit/runtime/`):

```
context-artifacts/
  ctx_<10 hex chars>/
    artifact.json          # ContextArtifact (metadata + selection + token estimates + compare result)
    prompt.md              # compressed prompt sent to model
    baseline.md            # selected files full text — created only on `context compare`
    response-compressed.md # last response from `send` or `compare` (compressed side)
    response-baseline.md   # last response from `compare` (baseline side)
```

`buildCompressedContext` is a **write-side-effect-free** usecase (not pure — it reads files and spawns `rg`). Disk writes are owned by the command layer (`ContextBuildCommand`) via `contextArtifactStore`.

`sendCompressedContext` and `compareCompressedContext` reuse the existing `runRoute` pipeline for all model interaction — including redact / budget gate / usage log / streaming / fallback. The compressed `prompt.md` content (or `baseline.md` content for the baseline side) is passed as the `task` input to `runRoute`, so the existing mode system prompt (plan/review/execute) wraps it naturally as a user message.

### 2. Types

```ts
// packages/core/src/context-compression/types.ts

export type SourceLanguage =
  | "ts" | "tsx" | "js" | "jsx"
  | "py" | "go" | "rs"
  | "md" | "json" | "yaml" | "toml" | "sh"
  | "other";

export interface ContextBudget {
  maxFiles: number;
  maxHotspotsPerFile: number;
  hotspotContextLines: number;
  /** Soft target for information only — not used to truncate prompt.md. */
  cloudTokenBudget?: number;
}

export interface RelevantFile {
  path: string;                     // workspace-relative
  score: number;                    // 0..1
  reason: string;                   // short human-readable
  matchedTerms: string[];
  termHitCount: number;
  pathBonus: number;                // breakdown for debugging
  mtimeBonus: number;
  sizeBytes: number;
  language?: SourceLanguage;
}

export interface SymbolEntry {
  kind: "import" | "export" | "function" | "class" | "interface" | "type" | "const";
  line: number;                     // 1-based
  text: string;                     // verbatim source line
}

export interface Hotspot {
  startLine: number;                // 1-based, inclusive
  endLine: number;                  // 1-based, inclusive
  matchedTerms: string[];
  code: string;                     // verbatim source for [startLine..endLine]
}

export interface FileExcerpt {
  path: string;
  language?: SourceLanguage;
  totalLines: number;
  skeleton: SymbolEntry[];
  hotspots: Hotspot[];              // adjacent/overlapping windows pre-merged
  omittedLineRanges: Array<[number, number]>;
  /** chars/4 ceil of rendered skeleton + hotspots only. */
  estimatedTokens: number;
}

export interface CompareSide {
  /** artifact-dir-relative path: "baseline.md" or "prompt.md". */
  inputPath: string;
  estimatedInputTokens: number;
  /** Provider usage if available (Anthropic / OpenAI / Ollama all report). */
  actualInputTokens?: number;
  actualOutputTokens?: number;
  actualCostUsd?: number;
  latencyMs?: number;
  /** artifact-dir-relative path: "response-baseline.md" or "response-compressed.md". */
  responsePath: string;
  /** Set when the stream emitted an error event mid-call. Phase continues regardless. */
  failureCode?: string;
}

export interface CompareResult {
  ranAt: string;                    // ISO timestamp
  profileId: string;
  baseline: CompareSide;
  compressed: CompareSide;
  savedInputTokensEstimate: number;
  /** Set only when both sides have actualInputTokens. */
  savedInputTokensActual?: number;
  /** Set only when both sides have actualCostUsd. */
  savedCostUsdActual?: number;
}

export interface ContextArtifact {
  id: string;                       // "ctx_" + 10 hex chars (from crypto.randomUUID)
  schemaVersion: 1;
  createdAt: string;                // ISO
  /** Absolute path. Document warning: artifacts contain local paths; do not share. */
  workspaceRoot: string;
  task: string;                     // verbatim user input
  keywords: string[];               // extracted (post-stopword, post-cap)
  budget: ContextBudget;            // resolved (CLI > config > default)
  ignoreGlobs: string[];            // resolved (default ∪ config ∪ CLI)
  candidates: RelevantFile[];       // top-N selected
  excerpts: FileExcerpt[];          // same order/length as candidates
  promptMdPath: string;             // "prompt.md" (artifact-dir-relative)
  /** NOT full repository — task + full text of selected candidate files only. */
  estimatedBaselineInputTokens: number;
  estimatedCompressedInputTokens: number;
  savedTokensEstimate: number;      // baseline - compressed
  compressionRatio: number;         // compressed / baseline (0..1)
  // Populated only after `tierkit context compare` runs:
  baselineMdPath?: string;          // "baseline.md"
  baselineEstimatedTokens?: number;
  compare?: CompareResult;
}

export const DEFAULT_CONTEXT_BUDGET: ContextBudget = {
  maxFiles: 8,
  maxHotspotsPerFile: 3,
  hotspotContextLines: 12,
};

export const DEFAULT_IGNORE_GLOBS = [
  "node_modules/**",
  ".git/**",
  "dist/**",
  "build/**",
  ".next/**",
  "coverage/**",
  ".tierkit/**",
  "*.lock",
  "pnpm-lock.yaml",
  "package-lock.json",
  "yarn.lock",
];
```

### 3. Config

Add optional section to `TierkitConfigSchema`. Three fields only — keep v1.7 surface minimal.

```ts
// packages/core/src/config/ConfigSchema.ts
export const ContextCompressionConfigSchema = z.object({
  defaultMaxFiles: z.number().int().positive().optional(),
  defaultCloudTokenBudget: z.number().int().positive().optional(),
  ignoreGlobs: z.array(z.string()).optional(),
}).strict();

// TierkitConfigSchema additions:
contextCompression: ContextCompressionConfigSchema.optional(),
```

**Resolution order:** CLI flag > `config.contextCompression` > `DEFAULT_CONTEXT_BUDGET`.

**`ignoreGlobs` policy:** *additive*, not replacement. Effective set = `DEFAULT_IGNORE_GLOBS` ∪ `config.contextCompression.ignoreGlobs` ∪ CLI `--ignore` values. Opt-out of defaults is not supported in v1.7.

**`cloudTokenBudget` / `--cloud-budget` policy in v1.7:** purely informational metadata stored in the artifact. It does NOT truncate `prompt.md`, does NOT cause `build` to print a warning when exceeded, and does NOT affect `compare` decisions. Reserved for v1.8+ when CompressionMode introduces actual budget enforcement.

### 4. CLI commands

```
tierkit context build "<task>"
  [--max-files N]
  [--max-hotspots N]
  [--hotspot-lines N]
  [--cloud-budget N]
  [--ignore PATTERN]     # repeatable
  [--cwd PATH]

tierkit context show <id>
  [--json]
  [--cwd PATH]

tierkit context send <id>
  --profile <profileId>                # required
  [--mode plan|review|execute]         # default: execute
  [--no-stream]
  [--cwd PATH]

tierkit context compare <id>
  --profile <profileId>                # required
  [--mode plan|review|execute]         # default: execute
  [--no-stream]
  [--yes]                              # skip confirm; required for non-TTY
  [--cwd PATH]
```

**`--cwd` semantics:** artifact lookup uses `<cwd>/.tierkit/runtime/context-artifacts/<id>/`. If `cwd` differs from `artifact.workspaceRoot`, print a warning and proceed:

```
Warning: artifact was built for /old/path but current cwd is /new/path
```

### 5. `tierkit context build` data flow

```
ContextBuildCommand
  └─ buildCompressedContext({task, workspaceRoot, budget, extraIgnoreGlobs})
       ├─ 1. resolveBudget(default → config → CLI overrides)
       ├─ 2. resolveIgnoreGlobs(default ∪ config ∪ CLI)
       ├─ 3. checkRgAvailable() → { ok: false, code: "rg-missing" } if missing
       ├─ 4. keywords = extractKeywords(task)
       │     - split whitespace, lowercase
       │     - drop stopwords (a, the, is, of, in, on, and, or, to, for, with, ...)
       │     - preserve quoted phrases as single tokens
       │     - extract identifiers (camelCase / snake_case / kebab-case)
       │     - drop 1-2 character non-identifier words
       │     - cap at 12, priority: quoted phrase > identifier > general word
       │     → empty → { ok: false, code: "no-keywords" }
       ├─ 5. candidates = collectCandidates(workspaceRoot, keywords, ignoreGlobs)
       │     - per keyword: rg --files-with-matches --line-number --ignore-case <kw>
       │     - merge into Map<path, MatchInfo>
       │     - plus rg --files → filename/path matches against keywords
       │     → empty → { ok: false, code: "no-candidates",
       │                 message: "No candidate files found. Try more specific terms or fewer --ignore patterns." }
       ├─ 6. ranked = rankCandidates(candidates, keywords, maxFiles)
       │     score = termHitScore + pathBonus + mtimeBonus
       │       - termHitScore = sum(log1p(matchCount) * idfWeight), normalized to 0..0.7
       │       - pathBonus    = 0.15 if any keyword appears in path/filename, else 0
       │       - mtimeBonus   = 0.15 * exp(-ageDays / 30)
       │     → top-N (maxFiles), deterministic tiebreak by path
       ├─ 7. excerpts = await Promise.all(ranked.map(async file => {
       │        const skeleton = extractSkeleton(fileContent, language);
       │        const hotspots = extractHotspots(fileContent, keywords, {maxHotspotsPerFile, hotspotContextLines});
       │        return { path, language, totalLines, skeleton, hotspots, omittedLineRanges, estimatedTokens };
       │      }))
       │     (composition lives inside buildCompressedContext.ts — no separate `extractFileExcerpt` module.
       │      Parallel file IO is fine here; sequential only matters for model calls in `compare`.)
       │     - extractSkeleton: regex per SourceLanguage; unknown extension → imports only
       │     - extractHotspots: matched line ± N, merge adjacent, top-K by density
       ├─ 8. promptMd = buildPromptMd(task, ranked, excerpts)
       ├─ 9. estimatedBaselineInputTokens  = ceil((task + sum(file_text)) / 4)
       │     estimatedCompressedInputTokens = ceil(promptMd / 4)
       └─ 10. return { ok: true, artifact } (no disk write)

ContextBuildCommand
  ├─ contextArtifactStore.write(workspaceRoot, artifact, promptMd)
  │     - mkdir .tierkit/runtime/context-artifacts/<id>/
  │     - write artifact.json
  │     - write prompt.md
  └─ print summary (artifact id, selected files, token estimates, next-command hints)
```

**Result union:**
```ts
| { ok: true; artifact: ContextArtifact }
| { ok: false; code: "rg-missing" | "no-keywords" | "no-candidates" | "workspace-not-found"; message: string }
```

`rg-missing` message must include install hints (`brew install ripgrep` / `apt install ripgrep` / `choco install ripgrep`).

**Stdout example:**
```

### 7. `tierkit context send` data flow

```
ContextSendCommand
  ├─ artifact = contextArtifactStore.read(workspaceRoot, id)
  ├─ if cwd ≠ artifact.workspaceRoot: print warning
  ├─ promptMd = read("<artifact-dir>/prompt.md")
  └─ result = await runRoute({
       cwd: workspaceRoot,
       task: promptMd,           # entire prompt.md becomes the user message
       profileId,
       mode,                     # plan/review/execute system prompt still applied
     })
     ├─ runRoute applies existing redact / budget / usage-log / streaming
     ├─ stream → stdout + write to response-compressed.md
     └─ done → footer with usage/cost/latency + response file path
```

**Policy:** `send` does NOT mutate `artifact.json`. `response-compressed.md` is last-write-wins.

### 8. `tierkit context compare` data flow

```
ContextCompareCommand
  ├─ artifact = contextArtifactStore.read(workspaceRoot, id)
  ├─ if cwd ≠ artifact.workspaceRoot: warning
  ├─ Phase 1 — pre-flight
  │   ├─ if artifact.compare exists: "previous compare result will be overwritten"
  │   ├─ baselineMd = buildBaselineMd(artifact)  # in-memory
  │   ├─ estimatedBaselineTokens = ceil(baselineMd / 4)
  │   ├─ if profile has costPer1MInputTokens:
  │   │   show "est input cost $X / $Y" per side
  │   └─ else: show "est input cost unknown"
  ├─ Phase 2 — confirm
  │   ├─ TTY × --yes matrix:
  │   │   TTY+!yes → "Continue? [y/N]"; empty/n/N → abort (exit 0)
  │   │   TTY+yes  → "proceeding (--yes)"
  │   │   !TTY+!yes → "use --yes to confirm in non-interactive mode" → exit 1
  │   │   !TTY+yes  → "proceeding (--yes, non-TTY)"
  │   └─ abort: print "Aborted. No model calls were made." and exit 0
  ├─ write baseline.md to disk (after confirm passes)
  ├─ Phase 3 — baseline call (sequential, baseline-first)
  │   ├─ print "═══ BASELINE ═══"
  │   ├─ result = runRoute({task: baselineMd, profileId, mode, cwd: workspaceRoot})
  │   ├─ if !result.ok (structural failure: unknown-profile, budget-exceeded, ...):
  │   │     print error; print "baseline.md was generated, but artifact.json was not updated."
  │   │     exit 1; DO NOT proceed to Phase 4
  │   ├─ stream → stdout + write response-baseline.md
  │   └─ collect actualInputTokens, actualOutputTokens, costUsd, latencyMs, failureCode?
  ├─ Phase 4 — compressed call (sequential)
  │   ├─ print "═══ COMPRESSED ═══"
  │   ├─ result = runRoute({task: promptMd, profileId, mode, cwd: workspaceRoot})
  │   ├─ if !result.ok: print error, still write partial compare with compressed.failureCode, exit 1
  │   ├─ stream → stdout + write response-compressed.md
  │   └─ collect side metrics (same as Phase 3)
  ├─ build CompareResult
  ├─ mutate artifact: set baselineMdPath, baselineEstimatedTokens, compare
  ├─ contextArtifactStore.write(artifact) — overwrites artifact.json
  └─ Phase 5 — print summary table (see below)
```

**Stream error vs. structural error:**
- `runRoute` returning `ok: false` is a **structural** failure (no call was made or budget refused) → abort the slice cleanly.
- `runRoute` returning `ok: true` then emitting an `error` stream event mid-call → record `failureCode` in `CompareSide`, **continue to the next phase** so the user keeps the partial result.

### 9. `tierkit context compare` output format

**Phase 1 pre-flight:**
```
[ctx_a3b2c1d4e5] tierkit context compare → claudeSonnet (anthropic/claude-sonnet, mode=execute)

⚠ previous compare result will be overwritten (last ran 2026-05-19T10:42:00Z)

About to make 2 paid model calls (estimated input cost only — output unknown):
  Baseline      ~72,400 input tokens   est input cost  $0.217
  Compressed     ~8,930 input tokens   est input cost  $0.027
  Token savings target:                ~63,470  (87.7%)

Continue? [y/N]
```

**Per-call sections (Phase 3 / 4):**
```
═══ BASELINE ═══════════════════════════════════════════════
[input: baseline.md, 72,400 tokens est]

{streamed response}

— baseline: 71,892 in / 412 out · 4,201ms · $0.215
  saved to: .tierkit/runtime/context-artifacts/ctx_.../response-baseline.md


═══ COMPRESSED ═════════════════════════════════════════════
[input: prompt.md, 8,930 tokens est]

{streamed response}

— compressed: 9,142 in / 387 out · 1,840ms · $0.014
  saved to: .tierkit/runtime/context-artifacts/ctx_.../response-compressed.md
```

**Phase 5 summary table:**
```
═══ COMPARE SUMMARY ═══════════════════════════════════════

                Baseline      Compressed      Savings
Input (est)     72,400        8,930           63,470  (87.7%)
Input (actual)  71,892        9,142           62,750  (87.3%)
Output          412           387             —
Cost            $0.215        $0.014          $0.201  (93.5%)
Latency         4,201ms       1,840ms         2,361ms  (56.2%)
Failures        none          none

Files in scope (5):
  app/api/payments/toss/route.ts
  app/premium-report/[id]/page.tsx
  lib/orders.ts
  app/api/payments/toss/init/route.ts
  lib/supabase.ts

Responses for side-by-side review:
  baseline:   .tierkit/runtime/context-artifacts/ctx_.../response-baseline.md
  compressed: .tierkit/runtime/context-artifacts/ctx_.../response-compressed.md
  Tip: compare these files in your editor or run `diff` / `git diff --no-index`.

Result saved to artifact:
  .tierkit/runtime/context-artifacts/ctx_.../artifact.json
```

**Output rules:**
- `Input (actual)` row appears only when both sides report provider usage; missing side → `—`.
- `Output` deliberately shows raw count only — no savings percent (output size ≠ quality).
- `Cost` and `Latency` savings percent appear only when both sides have actual numbers; else `unknown`.
- `Failures` shows `failureCode` per side when present, e.g., `baseline: stream-error   compressed: none`.

**`--no-stream`:** buffer both responses, print sequentially. Same section structure, no live deltas.

## Risks

| Risk | Mitigation |
| --- | --- |
| `ripgrep` not installed | `rg-missing` error includes per-OS install hints |
| Regex skeleton false negatives on edge syntax (decorators, generics) | Documented limitation in SPEC; tree-sitter deferred to v1.8+ |
| `chars/4` estimate inaccurate (~30% off for code) | compare summary shows both estimated and actual side-by-side; user sees the gap |
| `baseline` call cost surprise | pre-flight cost display + TTY confirm + `--yes` flag |
| Very generic task → `no-keywords` | clear error message guides user to more specific terms |
| Keyword cap=12 silently drops terms | priority order (quoted phrase > identifier > general) documented; surviving keywords visible in `tierkit context show` |
| compare re-run overwrites previous result | "previous compare overwritten" warning printed |
| User commits `.tierkit/runtime/context-artifacts/` (contains absolute paths + source excerpts) | README warning + `.tierkit/**` already in `DEFAULT_IGNORE_GLOBS` so the artifact dir won't be re-fed into a later `build` |
